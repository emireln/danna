# Platform logos

Logos for the platforms that learning links come from. `npm run logos` turns each one into a
small WebP file used in the app.

To add an official logo for a platform that has no logo yet, put its file here, named with the
platform id from `src/lib/platforms.ts`, for example `alura.svg` or `alura.png`. Then run
`npm run logos`. Official files take priority over the open icon set.
